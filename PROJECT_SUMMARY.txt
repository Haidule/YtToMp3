Language:       Python 3.10.6
GUI Framework:  tkinter (built-in)
Downloader:     yt-dlp 2026.2.4
Audio Tool:     FFmpeg 8.0.1
Audio Format:   MP3 @ 192kbps
Platform:       macOS

Architecture:
- Main thread handles GUI
- Worker thread handles downloads
- Progress hooks update UI in real-time
- FFmpeg automatically extracts audio
- Original video files are deleted
